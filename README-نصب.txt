بسته‌ی جایگزینی تغییرات نسخه‌ی v161

روش نصب:
1) ابتدا از برنامه‌ی فعلی از بخش «پشتیبان و امنیت» یک نسخه‌ی پشتیبان بگیرید.
2) این فایل ZIP را روی رایانه استخراج کنید.
3) پوشه‌ها را با همان ساختار در ریشه‌ی مخزن GitHub خود کپی کنید و فایل‌های هم‌نام را جایگزین کنید.
4) تغییرات را Commit و Push کنید.
5) پس از انتشار، در مرورگر یک بار صفحه را با Ctrl+F5 باز کنید. نسخه‌ی Service Worker به cl-v161 تغییر کرده تا کش قدیمی به‌روزرسانی شود.

فایل‌های اجرایی تغییرکرده:
- assets/js/core/app-core.js
- assets/js/features/daily-journal.js
- sw.js

فایل‌های مستندات به‌روزشده:
- CHANGELOG.md
- DAILY-JOURNAL-GUIDE.md
- TEST-REPORT.md

نکته‌ی مهم:
- شناسه‌ی دانش‌آموزان تغییر نمی‌کند.
- نمره‌ها و سوابق قبلی آزمون اصلی حذف یا بازنویسی نمی‌شوند.
- ارزشیابی جبرانی جدید در فیلد mkEval ذخیره می‌شود.
- قبل از جایگزینی، پشتیبان بگیرید؛ به‌خصوص اگر برنامه در حال استفاده و دارای اطلاعات واقعی است.
